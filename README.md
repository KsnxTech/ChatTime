# ChatTime

Простой плагин для отображения серверного времени в чате Minecraft перед ником игрока.

## Требования / Системные требования
* **Версия игры:** 1.18.2 (совместимость с другими версиями не тестировалась)
* **Ядро:** Paper / Purpur (использует Paper AsyncChatEvent)
* **Версия Java:** Java 17 или выше

## Сборка
Для сборки проекта используйте Maven:
\`\`\`bash
mvn clean package
\`\`\`
Готовый `.jar` файл появится в папки `target`.
